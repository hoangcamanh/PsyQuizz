# PsyQuizz Brand Assets

This directory houses the visual assets and brand identity files for **PsyQuizz**.

---

## 1. Brand Visual Identity Concept

The official brand identity comprises:
1. **Purple Mind Silhouette**: A profile silhouette representing human cognition, introspection, and mental well-being (`#674BBE`).
2. **Teal Sprout**: A sprout emerging from the mind, symbolizing personal development, self-discovery, and psychological resilience (`#14AC94`).
3. **Wordmark**: Clean, modern typography spelling **PsyQuizz** in deep charcoal (`#242730`).

---

## 2. Color Palette Tokens

| Token Name | HEX | RGB | Purpose |
|---|---|---|---|
| **Primary Purple** | `#674BBE` | `rgb(103, 75, 190)` | Brand anchors, primary buttons, major headings |
| **Accent Teal** | `#14AC94` | `rgb(20, 172, 148)` | Highlights, badges, growth icons, interactive accents |
| **Charcoal** | `#242730` | `rgb(36, 39, 48)` | High-contrast body text, primary wordmark |
| **Soft Lavender** | `#F4F0FC` | `rgb(244, 240, 252)` | Card surfaces, calm background panels, subtle borders |
| **Pure White** | `#FFFFFF` | `rgb(255, 255, 255)` | Main canvas background, input surfaces |

---

## 3. Typography Standards

- **Display & Headings**: `Nunito Sans` (SemiBold / Bold / ExtraBold) — friendly, human-centered, grounded.
- **Body & Interface Elements**: `Inter` (Regular / Medium) — neutral, highly legible, accessible at small sizes.
